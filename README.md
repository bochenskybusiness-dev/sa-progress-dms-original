# Прогресс Страхование — ДМС для сотрудников

Адаптивная версия страницы для просмотра и согласования.

- [Основная страница](./index.html)
- [ПК](./desktop.html)
- [Планшет](./tablet.html)
- [Телефон](./mobile.html)

Формы демонстрационные: данные не отправляются и не сохраняются.
Страница закрыта от индексации метатегом noindex.
Все используемые изображения, шрифты и скрипты размещены в этом репозитории.
